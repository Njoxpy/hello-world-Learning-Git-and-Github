## Commit Best Practices

- Use meaningull and descriptive commits which describes what you have done into your project.

- Consitentcy wording.If you are working with a team then consider using one way wording for commit message such past sense or present tense,It's advisable to use past tense over present tense.

```sh
# past
git commit -m "fixed bug"

# present
git commit -m "fix"
```

So make sure to use consistent style for wording.
